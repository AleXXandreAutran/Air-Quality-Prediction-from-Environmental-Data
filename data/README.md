# Dataset

Download and extract the original CSV from the [UCI Air Quality dataset](https://archive.ics.uci.edu/dataset/360/air+quality). Save it here as `AirQualityUCI.csv`, or pass its path with `--data`.

The script expects the original semicolon-separated file with decimal commas. The dataset is not included in this repository.

Source: [Vito, S. (2008). Air Quality. UCI Machine Learning Repository](https://doi.org/10.24432/C59K5F). Check the dataset page for its terms and citation details.
